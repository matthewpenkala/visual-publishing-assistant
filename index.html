Careful Pinterest workflows, under the user’s control.

Visual Publishing Assistant connects an authenticated Pinterest account through Pinterest OAuth and API v5. It supports live account reads, native curation of existing public Pins, attributed source-linked inspiration saves, and preparation of finite organic image and video Pin tasks on supported media-probe architectures. Production publishing remains gated on Pinterest Standard access and successful live readback.

Product principles

Built for a private, local-first MVP.

Official authorization

Pinterest passwords and browser cookies are never requested. Account access uses Pinterest’s OAuth Authorization Code flow.

Local secret storage

The operator App ID, App secret, and OAuth token record stay in one owner-only local file: protected POSIX modes on macOS or a protected current-user NTFS access list on Windows.

Bounded authorization

A request naming an exact destination and finite operation set authorizes only that task end to end. It never authorizes future, unrelated, destructive, or open-ended writes, and ambiguous creates are not blindly retried.

Minimal retention

Pinterest account content is read live, not stored in a durable product database. Outbound drafts are short-lived and in memory.

Current scope

Organic account operations and Standard-gated publishing.

  • Read the connected user’s profile, relationships, organic analytics, boards, sections, and Pins with bounded pagination.
  • Save existing public Pins through Pinterest’s native curation endpoint and retain source links and attribution for supplied external references.
  • Create, read, update, or explicitly delete boards and sections; prepare and validate bounded image or video Pins, with production publish/update/delete capability reported only after the applicable live entitlement and readback gate.
  • Retrieve a complete bounded board export ephemerally, or explicitly download available media with safe filenames, a manifest, deduplication, and partial-failure reporting.
  • Keep secret-board permissions, advertising, commerce, and catalogs outside the default scope.
  • Keep user-requested public visual research separate from authenticated account operations.

Current access boundary: Pinterest Trial permits live reads, but the production API denied Create Pin with code 29 after a successful video media upload and processing sequence. Standard access and a successful production readback remain required before production publishing is described as ready. Sandbox is test-only and ordinary publishing never falls back to browser automation.

Platform boundary: Local video inspection is packaged for macOS and Windows x64/ia32. Windows ARM64 retains connection, image, curation, board, Pin-read, and export workflows, but local-video preparation remains unavailable pending a compatible packaged probe.
