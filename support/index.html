Support

How can we help?

Visual Publishing Assistant is currently an internal, local-first macOS and Windows Codex integration published and operated by Matthew Penkala.

Contact

For connection, privacy, deletion, or security questions, use the protected address: Reveal email address.

Include safely

Include the app version, the operation being attempted, and any redacted error message. Never send a Pinterest password, App secret, access token, refresh token, authorization code, cookie, or unredacted account payload.

Local reset

The product provides separate local controls to disconnect the connected Pinterest account or remove the complete local operator configuration. These controls do not delete Pinterest content. Pin, board, or section deletion requires a separate instruction that explicitly names the destructive action and exact target.

Production access

Pinterest Trial currently supports the integration’s live account reads, but production Create Pin returned code 29 and requires Standard access. Sandbox entities are separate tests, and ordinary Pin publishing is never routed through browser automation.

Local-video inspection is packaged for macOS and Windows x64/ia32. On Windows ARM64, connection, image, curation, board, Pin-read, and export workflows remain available, while local-video preparation reports that the compatible probe is unavailable.
